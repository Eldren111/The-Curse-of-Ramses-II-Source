# 探索者罗盘：耐久附属

独立的 **Minecraft 1.20.1 / Forge 47.x / Java 17** 附属模组，前置是 [dreamforSh/ExplorersCompass](https://github.com/dreamforSh/ExplorersCompass) 的 Forge 1.20.1 版本。

## 安装与使用

将 `explorers-compass-durability-1.20.1-forge-1.0.0.jar` 和前置罗盘模组一起放入 `mods`。多人游戏的服务端、客户端都安装本附属。

- 直接作用于原模组的罗盘，包括已经合成的罗盘；不添加新物品或新配方。
- 默认最大耐久 **240**，每次发起搜索消耗 **1** 点。
- 单项搜索、多选搜索、分组搜索、搜索下一个，每次请求只计费一次。前置的生物群系搜索走同一入口，也会计费。
- 只打开界面、潜行取消搜索、查看或选择已有书签不计费。前置拒绝的冷却中请求不计费；已经开始但未找到目标的搜索仍计费。
- 搜索下一个失败后，前置内部自动从头查找不会额外扣费。
- 耐久耗尽会销毁罗盘。由于搜索是异步的，耗尽耐久的最后一次请求可能在结果返回前随罗盘损坏而结束。
- 创造模式与带原版 `Unbreakable` 标签的罗盘不消耗；普通罗盘严格扣除配置值，不受耐久附魔的随机减免影响。
- 显示原版耐久条，F3+H 可查看精确剩余耐久。取消搜索不会恢复耐久。没有额外增加修复配方。

## 配置（只有两项）

首次进入世界后自动生成：

```text
单机：saves/<存档名>/serverconfig/explorerscompassdurability-server.toml
服务端：<世界目录>/serverconfig/explorerscompassdurability-server.toml
```

```toml
# 罗盘最大耐久。默认 240；必须大于 0。
maxDurability = 240
# 每次发起搜索消耗的耐久。默认 1；0 表示不消耗。
damagePerUse = 1
```

以服务端配置为准，Forge 会同步到连接的客户端。建议关闭世界/停服后修改，再重新进入世界。整合包可将同名文件放入 `defaultconfigs` 作为新世界的默认配置。已有世界应修改自身 `serverconfig`。

已有罗盘保留已消耗耐久数：例如原本已消耗 20，最大耐久由 240 改为 100 后，剩余为 80。如果已消耗值达到新上限，下次计费时损坏。每次消耗允许大于最大耐久，效果是一次用尽。

## 结构汉化

内置 Minecraft 1.20.1 全部原版结构与结构分组的简体中文名称（包括古迹废墟）。游戏语言选择“简体中文”，并在前置罗盘中开启“翻译结构名称”（`translateStructureNames`）。

采用前置已支持的 `structure.<命名空间>.<路径>` 语言键，继续兼容其他模组及资源包已有的翻译；没有翻译的第三方结构仍显示前置提供的名称，不根据英文标识猜译。

例如结构 `example:ruins/desert` 对应语言键：

```json
{
  "structure.example.ruins.desert": "沙漠遗迹"
}
```

可放入资源包 `assets/example/lang/zh_cn.json`。资源包格式为 15。这里翻译的是罗盘列表、分组及使用前置翻译函数的界面名称；前置服务端输出的部分聊天消息使用硬编码基础名称，不在本附属的界面语言覆盖范围内。

## 兼容范围与验证

已核对指定仓库 1.20.1 分支中标记为 **1.4.0、1.5.0、1.5.1、1.5.3、1.5.9、1.6.0** 的源码接口。具体提交和复核脚本见 `verification` 与 `scripts/verify-upstream.ps1`。

附属不绑定某个前置 JAR 编译，使用这些版本共有的罗盘类及搜索入口；版本依赖没有锁死某个补丁号。Mixin 必须成功注入，否则明确报错，避免悄悄失去耐久功能。1.19.2、1.21.1、Fabric、NeoForge 不在本项目范围内。未来前置如果改变类名或搜索签名，需要重新检查，不能预先保证。

验证分为构建、耐久边界单元测试和历史源码接口核对；**尚未启动 Minecraft 客户端或专用服务器做游戏内实测**。发布到整合包前，建议在测试世界确认主手/副手搜索、取消搜索、联机同步、耐久耗尽与语言资源包覆盖。

## 构建

设置 `JAVA_HOME` 指向 JDK 17，在本目录执行：

```powershell
.\gradlew.bat build
```

产物在 `build/libs/`。工程独立构建，不依赖当前工作区其他模组，也不打包前置源码或资产。
